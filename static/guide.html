Install it in a minute, then reply to any message in three clicks. No coding needed.

1. Installing the extension

Works in Google Chrome, Microsoft Edge and Brave on a computer.

1

Download and unzip

On the home page, click Download the extension. In your Downloads folder, right-click ai-reply-helper.zip → Extract All… → Extract.

2

Open the extensions page

Type chrome://extensions in the address bar and press Enter (Edge: edge://extensions).

3

Turn on Developer mode

Switch on Developer mode in the top-right corner.

4

Load the folder

Click Load unpacked and choose the unzipped ai-reply-helper folder (the one with manifest.json inside).

5

Pin it

Click the puzzle icon 🧩 next to the address bar, then the pin 📌 next to AI Reply Helper.

💡 Keep the unzipped folder. If you delete it, Chrome removes the extension.

2. Writing a reply

1

Select the message

On any website (Gmail, LinkedIn, a review, a comment…), highlight the message with your mouse.

2

Open the helper

Click the 💬 icon in your toolbar, or right-click the selected text and choose Reply to this with AI. The message is filled in for you. (No selection? Paste the message into the box.)

3

Choose the tone and goal

Pick a tone, choose what you want to say, and optionally add a detail. Then click Write 3 replies.

4

Copy and send

Click Copy under the reply you like, then paste it (Ctrl + V) where you're replying. Not quite right? Click Try different replies.

4. Tips for better replies

  • Select the whole message, including the sender's name, so the reply can greet them.
  • Add the facts you know. The helper won't invent dates, prices or promises. It writes [date] instead, so you can fill it in.
  • Check before sending. Replace placeholders like [Your Name] and make sure it says what you mean.
  • For a reply in another language, just select a message in that language.

6. FAQ

Is it free?

Yes. It runs on Google Gemini's free tier, with fair-use limits per hour.

Does it send my emails anywhere?

Only the text you select, and only when you click Write 3 replies. It's sent to the AI to write the replies and not stored. See the privacy page.

Does it send the reply for me?

No. You always choose, copy and send the reply yourself.

Can you build a custom extension for me?

Yes. See the Developer section.
